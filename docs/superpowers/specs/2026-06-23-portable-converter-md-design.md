# PortableConverterMD 设计文档

> 日期：2026-06-23 | 状态：待审查

## 目标

将 Microsoft MarkItDown 封装为 Windows 桌面工具，单个 `.exe` 下载即用，面向普通用户。

## 用户体验

- 拖拽/选择文件 → 文件列表展示，默认全选
- 点击「开始转换」→ 后台转换，按钮变灰+进度条
- 全部完成后可点击「打开输出目录」
- 输出位置：原文件所在目录下新建 `md_output` 文件夹，同名 `.md` 输出

## 窗口布局

```
┌─────────────────────────────────┐
│  📁 拖拽文件到此处（或点击选择）  │
├─────────────────────────────────┤
│  ☑ report.docx      123KB      │
│  ☑ slides.pptx      5.2MB      │
├─────────────────────────────────┤
│  状态：已转换 2/2               │
│  [ 开始转换 ]  [ 打开输出目录 ]  │
└─────────────────────────────────┘
```

## 架构

- 单文件 `main.py`，~250 行
- 依赖：`markitdown` + `PySide6`
- 打包：PyInstaller → 单个 `.exe`（约 200-350MB）
- 后台转换用 `QThread`，不卡 UI

## 支持格式

MarkItDown 全部支持格式：Office（Word/Excel/PPT）、PDF、图片（OCR）、HTML、CSV、JSON、XML、音频、ZIP 等。

## 数据流

```
拖拽/选择 → 文件列表 → 开始转换 → QThread 逐个转换
                                        ↓
                                  进度条更新
                                        ↓
                                  全部完成 → 打开输出目录
```

## 交互细节

- 拖入文件自动列出，默认全选
- 可取消勾选、删除单项、清空列表
- 转换中按钮不可点击
- 输出文件夹：源文件目录下统一的 `md_output/`
- 完成弹通知 + 「打开输出目录」按钮

## 不做的

- 无 Markdown 预览区
- 无多文件目录结构（单文件实现）
- 无转换设置/选项（全默认行为）
- 无系统托盘、菜单栏
